<h1 align="center">EsimCard</h1>

<p align="center">
  Android-приложение для модулей eSIM <a href="https://esimcard.ru">EsimCard</a>
</p>

---

Модуль EsimCard вставляется в обычный слот SIM-карты и превращает любой Android-смартфон в телефон с поддержкой eSIM. Приложение управляет eSIM-профилями на модуле.

## Возможности

- Загрузка eSIM-профилей по QR-коду или коду активации
- Несколько профилей на одном модуле и переключение между ними в пару касаний
- Переименование и удаление профилей
- Информация о модуле: EID, свободная память

## Скачать

- **[Последняя версия на GitHub](https://github.com/annarkin/esimcard-android/releases/latest)**
  - `arm64-v8a` — для большинства современных телефонов
  - `armeabi-v7a` — для старых 32-битных телефонов

Устанавливайте приложение только из официальных источников: RuStore, esimcard.ru или эта страница.

## Требования

- Модуль EsimCard (или другая совместимая eSIM-карта) в слоте SIM
- Android 7 и новее

## eSIM для путешествий

Тарифы eSIM для поездок за границу — на [esimcard.ru](https://esimcard.ru): покупаете, сканируете QR-код в приложении и пользуетесь интернетом без роуминга и поиска местной SIM-карты.
